# Dataset Setup

The raw used-car dataset is not included in this repository.

Place your dataset under:

```text
data/raw/
```

The analysis expects a dataset of second-hand car sales containing fields such as manufacturer, model, engine size, fuel type, year of manufacture, mileage and price.

Before running the notebook, check the data-loading cell and update the filename/path to match your local copy. Running Jupyter from the repository root is recommended so relative paths can be used consistently.
